# FakeBadges

A Vencord plugin that adds **local-only profile badge previews** to your own Discord client, with a redesigned settings interface.

> **Important:** FakeBadges changes only what is rendered in your local Discord client. It does not grant real Discord badges, modify Discord account data, or make the badges visible to other users.

## Features

- Enable or disable badge previews locally.
- Choose from classic Discord-style badge designs.
- Configure experimental badge categories and their visual levels.
- Option to hide original badges in your own client.
- Custom settings interface integrated into the plugin.

## Installation

1. Install [Vencord](https://vencord.dev/).
2. Download `index.ts` from this repository.
3. Place it in your Vencord userplugins directory.
4. Restart Discord and enable **FakeBadges** in Vencord settings.

For the latest Vencord plugin development and userplugin instructions, see the [Vencord documentation](https://docs.vencord.dev/).
